# Documentation and Result Artifacts

This folder contains the public notebooks, generated figures, summary CSVs, and
long-form instructions for the TRPO/PPO empirical benchmarking project.

## Result Workflow

The training runs were launched and managed with
[`colab_runmanager.ipynb`](colab_runmanager.ipynb). That notebook is kept here as
a reference for the run orchestration workflow: launching jobs, resuming runs,
and collecting completed run folders.

Those runs write their metrics, resolved configs, launch metadata, runtime
metadata, and environment snapshots into [`../outputs/`](../outputs/). PyTorch
checkpoint weights are intentionally kept out of git, but the lightweight run
records are public so the plots and tables can be regenerated.

The analysis notebook,
[`aggregate_results_plots.ipynb`](aggregate_results_plots.ipynb), reads from
[`../outputs/`](../outputs/) and uses
[`../scripts/aggregate_results.py`](../scripts/aggregate_results.py) to aggregate
seeds, plot learning curves, export PDF figures, build CSV summaries, and print
run sanity-check tables.

## Contents

| Path | Purpose |
|---|---|

## Figures and Summaries

| Folder | What it contains |
|---|---|
| [`figures_and_summaries/locomotion/`](figures_and_summaries/locomotion/) | PDF training curves and CSV summaries for `Hopper-v5`, `Swimmer-v5`, and `Walker2d-v5`, comparing TRPO, NPG, and PPO-Clip across three seeds. |
| [`figures_and_summaries/atari/`](figures_and_summaries/atari/) | PDF training curves and CSV summaries for the six Atari tasks, comparing TRPO and PPO-Clip for the completed seed-0 runs. |
| [`figures_and_summaries/npg_ablation/`](figures_and_summaries/npg_ablation/) | PDF and CSV outputs for the Hopper NPG step-size ablation, including the NPG-only comparison and the combined TRPO/NPG/PPO overlay. |

For each plotted comparison, the `.pdf` file is the report-ready figure, the main
`.csv` file contains the aggregated plotting data, and the `__summary.csv` file
contains the compact table used for sanity checks and report summaries.
